📌 Functional Requirements
1. After launching, the app should display characters using the `/character` endpoint.
* For each character, show: Thumbnail, Name, Number of episodes the character appeared in. 
* Display 20 characters.
2. Users should be able to search for a character by name.
3. Tapping on a character should display a detailed view with:
* Photo/Image
* Name
* Status
* Species
* Gender
* Current location

⚙️ Technical Requirements
* Make use of the Rick and Morty REST API.
* Use your own code to communicate with the API. (do not use a 3rd party Rick and
Morty SDK) - you can use third party library for image caching only.


Link:- https://rickandmortyapi.com/
